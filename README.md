# Show HN: Filebrowser Alternative

## What it does

Show HN: I made an alternative to the archived filebrowser. This project showcases how to create a modern, lightweight file browser using HTML, CSS, and JavaScript. The filebrowser is designed to be simple and intuitive, allowing users to navigate through files and directories efficiently.

## How to run it

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yourusername/show-hn-filebrowser.git
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd show-hn-filebrowser
   ```

3. **Open `index.html` in a Web Browser:**
   - You can use any modern web browser to open the `index.html` file. For example:
     ```bash
     open index.html
     ```

## Setup Steps

1. **Install Dependencies:**
   - Ensure you have Node.js and npm installed on your system. You can download them from [nodejs.org](https://nodejs.org/).

2. **Install Project Dependencies:**
   - Run the following command to install the necessary dependencies:
     ```bash
     npm install
     ```

3. **Start the Development Server:**
   - Use the following command to start a development server that serves your project:
     ```bash
     npm run serve
     ```
   - This will open a local development server at `http://localhost:3000`, allowing you to view and test your filebrowser in real-time.

## Project Files

- **index.html**: The main HTML file that defines the structure and layout of the file browser.
- **styles.css**: The CSS file that styles the file browser, including colors, typography, and layout.
- **script.js**: The JavaScript file that adds functionality to the file browser, such as navigation, file selection, and drag-and-drop support.

## Idea Source

This project was inspired by the archived filebrowser found at [https://github.com/skidoodle/filebrowser](https://github.com/skidoodle/filebrowser). The filebrowser is designed to be a lightweight and responsive alternative to the original, making it easier to use on various devices and screen sizes.
